Volcano is a small tool for retrieving the content of an Obsidian vault as structured data. You can use it to build a blog, wiki, personal website, or anything else you can imagine.

## Features

- Query your vault and note data in a format you can use
- Automatically resolve internal links and image URLs
- Verify frontmatter according to schemas you define
- Resize images
- Use shortcodes to programmatically insert content, even if the content needs to be fetched from somewhere else
- Pluggable caching interface to work across a variety of stacks
